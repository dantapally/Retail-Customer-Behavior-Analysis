# Retail Customer Behavior Analysis

## Project Overview
This Power BI project analyzes retail customer purchasing behavior and provides business insights through interactive dashboards.

## Tools Used
- Power BI
- Excel / CSV
- Data Visualization
- DAX

## Dataset Features
- Customer Demographics
- Purchase Amount
- Customer Persona
- Loyalty Segment
- Payment Method
- Shipping Type
- Season
- Product Category

## Dashboard Pages

### Executive Dashboard
Key KPIs:
- Total Revenue
- Total Customers
- Average Order Value
- Average Review Rating

Visuals:
- Revenue by Category
- Revenue by Age Group
- Revenue by Customer Persona
- Revenue by Loyalty Segment
- Revenue by Customer Value

### Customer Deep Dive
Detailed analysis of:
- Revenue by Gender
- Revenue by Season
- Revenue by Payment Method
- Revenue by Subscription Status
- Revenue by Shipping Type

## Key Insights
- Discount Driven customers generate the highest revenue.
- Clothing category contributes the most revenue.
- Loyal customers spend more than new customers.
- Male customers contribute higher revenue than female customers.
